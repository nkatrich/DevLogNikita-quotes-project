# Проект Just Quotes



**Про что проект?**

Проект про цитаты где всего 25 цитат и выводится на дисплей

**Как пользоватся проектом?**

Нажимая на стрелки выводится следующия/предыдущия цитата.

**Технологии используемые в проекте**

* Массив с обьектами где: автор и цитата
* Массив сборщик, где из основного массива собирает рандомный массив с обьектами(для полной рандомности)
* Индекс переменная, при нажатии на кнопку вызова массива, она будет увеличиватся и уменшатся, а значит, управление конкретнного индекса массива, что бы вызвать обьект из массива на дисплей.
* Анимация используя: RAF а так reset CSS базовые анимации, так как на кнопки можно нажимать неограниченное количество раз.
* Управление с клавиатуры для вызова цитат, используя стрелки клавиатуры, стрелка влево - прошлая цитата. Стрелка вправо - следующия цитата.
* В проекте используется RAF, а в нем же второй RAF, что бы сайт гарантировал вывод анимации на экран.
* В проекте присутствует коментарии, код читабельный
